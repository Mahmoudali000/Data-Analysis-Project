# Data Analysis Project 📊
# Comprehensive Sales & Revenue Optimization Dashboard

## 📌 Project Overview
This project delivers an interactive, high-level Sales Dashboard designed to analyze retail commercial data. The objective is to identify key sales trends, map geographical performance, and analyze customer segments to help upper management make data-driven decisions that boost profit and optimize marketing budgets.

## 🛠️ Skills & Tools Used
* Tableau (Advanced): Used to design and build an interactive, data-driven dashboard with a professional Dark Theme for smooth executive reporting.
* Python: Applied for the initial data cleaning, manipulation, and handling of raw sales datasets.
* Microsoft Excel: Utilized for data mapping, baseline calculations, and schema exploration.

## 🎯 Key Insights & Business Solutions
* Geographical Mapping: Built a custom Interactive Map to track sales density across different states, helping the business identify underperforming areas and allocate regional resources effectively.
* Temporal Trend Analysis: Developed a dynamic Line Chart (Sales Over Time) to capture seasonal peaks and revenue drops, enabling management to accurately forecast demand.
* Product Performance Tuning: Visualized "Sales by Category" and "Sales by Product" to quickly spot high-margin items versus slow-moving stock, optimizing inventory costs.
* Customer Segmentation: Integrated a "Sales by Segment" analyzer to differentiate purchasing behaviors between Consumer, Corporate, and Home Office clients, maximizing marketing ROI.
